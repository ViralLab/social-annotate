About This Tool

Human annotated data is a crucial component in the analysis of online systems. Most research efforts go through cumbersome data collection phases where they either build complicated annotation pipelines for online data or annotate offline data shared on spreadsheets. We aim to develop a tool that can easily adapt to different tasks and extend to most online platforms.

This tool allows collection of data directly on the online platform by injecting surveys into webpages on the browser. Annotations can be exported as files or sent to API endpoints.

How to Modify Options

Each survey is listed under "Surveys" in the Options tab. Form objects follow the jsonform schema format — use the "Preview Survey" button to see your changes rendered live before saving.
